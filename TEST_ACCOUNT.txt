================================================================================
                        API TESTING
================================================================================

Authentication:
POST http://localhost:8000/api/v1/auth/login
Body: {
  "email": "redis_test@example.com",
  "password": "testpass123"
}

Chat (with conversation memory):
POST http://localhost:8000/api/v1/chat/
Headers: { "Authorization": "Bearer YOUR_TOKEN" }
Body: {
  "text": "I spent 100 dollars on groceries yesterday",
  "chat_id": "optional-chat-id-from-previous-response"
}

Get Conversation History:
GET http://localhost:8000/api/v1/chat/{chat_id}/history
Headers: { "Authorization": "Bearer YOUR_TOKEN" }

Clear Conversation:
DELETE http://localhost:8000/api/v1/chat/{chat_id}
Headers: { "Authorization": "Bearer YOUR_TOKEN" }
